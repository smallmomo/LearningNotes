# 提示词关键词速查表

选词时优先使用简洁精准的中文关键词；为 Midjourney 等英文工具生成时，使用英文参考列。

## 表1 常用构图关键词

| 类别 | 中文关键词 | 英文参考 | 说明 |
| ---- | ---- | ---- | ---- |
| 景别 | 特写 / 大特写 | Close-up / Extreme Close-up | 强调面部或物体局部细节 |
| 景别 | 胸像 / 半身像 | Bust shot / Medium Close-up | 人物胸部以上 |
| 景别 | 中景 | Medium Shot | 膝盖或腰部以上，能看到部分环境 |
| 景别 | 全身像 / 全景 | Full Shot / Long Shot | 完整展示主体，交代环境 |
| 景别 | 远景 / 大远景 | Distant Shot / Extreme Long Shot | 突出环境广阔，主体较小 |
| 视角 | 正面 / 侧面 / 背面视角 | Front / Side / Back View | 从对应方向拍摄 |
| 视角 | 鸟瞰视角 / 俯视 | Bird's-eye View / Top-down View | 从高处向下看 |
| 视角 | 仰视视角 / 虫瞻视角 | Worm's-eye View / Low Angle Shot | 从低处向上看，凸显主体高大 |
| 视角 | 平视 | Eye-level Shot | 最自然客观的视角 |
| 视角 | 荷兰角 / 倾斜构图 | Dutch Angle / Canted Angle | 画面倾斜，营造不稳定感或动感 |
| 视角 | 第一人称视角 | First-person Perspective / POV | 模拟角色亲眼所见，增强代入感 |
| 布局 | 对称构图 | Symmetrical Composition | 元素对称分布，稳定庄重 |
| 布局 | 黄金分割 / 三分法 | Golden Ratio / Rule of Thirds | 主体置于分割线交点或线上 |
| 布局 | 引导线构图 | Leading Lines | 利用线条引导视线聚焦主体 |
| 布局 | 框架式构图 | Framing Composition | 前景元素形成框架，突出主体 |
| 布局 | 居中构图 | Centered Composition | 主体位于画面中央 |
| 其他 | 肖像 / 风景 | Portrait / Landscape | 分别强调人物面部 / 自然城市景观 |
| 其他 | 动态模糊 | Motion Blur | 表现运动速度感 |
| 其他 | 景深 / 背景虚化（散景） | Depth of Field / Bokeh | 主体清晰背景模糊，突出主体 |
