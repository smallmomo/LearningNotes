# 图片提示词生成

## 目的

基于结构化提示词方法论生成高质量AI绘画提示词。中文优先，适配豆包、即梦、可图等国内主流工具；用户明确要求英文提示词时，按相同结构输出英文版本。

## 核心公式

```
提示词 = 核心主体 + 细节描述 + 环境与背景 + 风格修饰 + 构图与视角
       + 光影与色彩 + 质量与渲染 + 参数（可选）+ 反向提示词（可选）
```

## 执行流程

### 第一步：判断模式

| 模式 | 判定条件 | 使用模板 |
| ---- | ---- | ---- |
| A 只有人物 | 描述仅涉及人物，无明确环境要求（肖像、角色设定图等） | 人物模板 |
| B 只有场景 | 描述仅涉及环境/风景/建筑/氛围，无人物主体 | 场景模板 |
| C 人物加场景 | 人物处于具体环境中的画面 | 组合模板 |
| D 提示词反推 | 用户提供图片或图片描述，要求反推出能生成类似效果的提示词（图生文） | 反推工作流 |
| E 故事分镜 | 用户要求连续画面、分镜、故事板、绘本、漫画序列、多张连贯图片 | 分镜工作流 |

用户未明确指定时从描述内容推断；无法推断时默认使用 C（信息最完整）。A/B/C 为单图生成，D/E 为专用工作流，同样先执行第二步资产库定位。

### 第二步：定位并读取资产库（必做）

资产库路径不写死，按以下优先级动态定位：

1. 用户在会话中明确指定的资产库路径（最高优先级）
2. 从本 skill 所在目录向上逐级查找名为 `prompt` 的目录（如 `<skill目录>/../prompt`、`<skill目录>/../../prompt`）
3. 在当前工作区内搜索名为 `prompt` 的目录（glob `**/prompt`），优先选择包含提示词资产文件的目录
4. 以上均未找到时跳过资产库，按标准模板生成

定位成功后：

1. 列出该目录下的文件，识别其中的提示词资产（.md/.txt 格式、内容为完整提示词或关键词组合的短文档；方法论教程、长篇读书笔记类文档跳过不读）
2. 读取资产内容，学习用户沉淀的优质提示词的风格、结构与关键词组合
3. 生成时优先复用资产库中已验证有效的风格、光影、构图等关键词组合，保持与用户偏好一致
4. 目录为空或无资产文件时跳过，按标准模板生成

**资产沉淀规则**：当用户表示某次生成效果较好时，将该提示词保存到已定位的资产库目录（定位不到时先向用户确认路径），文件命名规范：`模式-主题-序号.md`（如 `人物-赛博侦探-01.md`），文件内包含完整提示词、反向提示词与一句话效果点评。

### 第三步：确认必填字段并生成

标注【必填】的字段是生成提示词不可或缺的核心信息，处理规则如下：

- 必填字段缺失：必须向用户提问确认，**不得自行假设或编造占位内容**。将缺失的多个必填项合并为一组问题一次性提出（如"请补充：①人物身份 ②服饰外观 ③动作 ④情绪"），避免来回打断。
- 非必填字段缺失：可基于语境合理补全，并在输出的【要素拆解】中标注"已自动补全"，供用户按需调整。
- 模式 D 反推需用户提供图片或图片描述；模式 E 分镜需用户提供故事内核（一句话 What）。缺失时同样先提问再生成。

确认全部必填字段后，按以下模板组装：

#### 模板A：只有人物

1. 身份与类型【必填】：年龄、性别、职业/身份、物种（人类/精灵/机器人/龙等）
2. 外观特征【必填】：发型发色、面部特征、服饰（含材质与颜色，如"深紫色丝绒长袍"）、配饰
3. 姿态与动作【必填】：具体动作（阅读、挥剑、望向远方），多用具象动词
4. 情绪与表情【必填】：开心/悲伤/惊讶/平静/坚定等
5. 景别与视角：特写/半身像/全身像，正面/侧面/仰视等（人物常用特写突出情绪）
6. 风格修饰：艺术流派/媒介技法/视觉效果
7. 光影与色彩：人物肖像优先考虑伦勃朗光、边缘光、柔和光线
8. 质量与渲染：高细节、锐利对焦（适度使用，2~3 个词即可）
9. 可选：画幅参数、反向提示词（手部变形、文字、水印等）

#### 模板B：只有场景

1. 地点【必填】：室内/室外/具体地标（可虚构，如"迷雾山谷、水晶洞穴"），力求具体
2. 时间与天气【必填】：黎明/黄昏/黄金时刻/雨夜/飘雪/有雾等
3. 环境元素：自然元素（树木、河流、星空）、人造元素（建筑、灯光）、氛围道具（飘落的叶子、燃烧的壁炉）
4. 光线与色彩【必填】：光线类型（体积光/霓虹灯/月光）+ 色彩基调（暖色/冷色/莫兰迪色系）
5. 氛围与情绪【必填】：宁静/神秘/荒凉/梦幻/喧嚣等
6. 景别与视角：远景/全景/鸟瞰/框架式构图（场景常用远景或鸟瞰展现空间）
7. 风格修饰 + 质量渲染（同上，适度）

#### 模板C：人物加场景

1. 人物块：身份、外观、动作、情绪（同模板A要素1~4）
2. 场景块：地点、时间天气、环境元素（同模板B要素1~3）
3. 互动关系【必填】：设计人物与场景的具体互动（"她撑伞走过雨巷"优于"她站在雨巷里"），让画面有故事性
4. 景别叙事：远景突出环境宏大、中景平衡人物与环境、特写突出人物情绪——按叙事意图选择
5. 风格修饰：人物与场景风格必须统一协调
6. 光影与氛围：人物与环境共享同一光源（如"黄昏的暖光同时照亮人物和街道"）
7. 质量渲染 + 可选参数/反向提示词

#### 模式D：提示词反推（图生文）

用户提供图片或对图片的描述，反推出能生成类似效果的提示词。

1. 拆解图片：按核心公式逐项分析——核心主体、细节特征、环境背景、艺术风格、构图视角、光影色彩
2. 重组为提示词：优先保留核心元素（主体、主要风格、构图、光影），避免事无巨细全部罗列
3. 声明局限：反推结果是对原图的"解读"而非精确还原，与原作者实际提示词可能不一致
4. 引导四步加工（输出后必须给出）：
   - 筛选：按画风、主题、细节准确性甄别各要素
   - 优化：替换更精准的同义词，调整词语顺序
   - 补充：加入图中未体现但用户想要的元素（情感氛围、风格细节）
   - 删除：剔除与目标无关、冗余、冲突或降低质量的词
5. 原创性提醒：反推用于学习启发，再创作需注入独创性，不可直接复制他人作品商用

#### 模式E：故事分镜（连续画面）

用户需要一组有叙事关联的画面（分镜、绘本、漫画、连环图）。

1. 确立故事内核：一句话概括是什么（What）+ 想传达什么（Why）
2. 按"开端—发展—高潮/结局"三幕结构规划分镜：
   - 开端：介绍角色、环境、初始状态，侧重氛围渲染与角色形象塑造
   - 发展：引入冲突/挑战/转折，展现动态变化与情绪逐步演变
   - 高潮/结局：展现关键时刻的张力，或最终的宁静/释然
3. 每个分镜输出三要素：画面描述（1~2句）+ 构图设计（景别+视角）+ 完整提示词
4. 镜头设计按叙事意图选景别——远景交代环境背景、全景展示整体动作、中景展现交流互动、近景传递情感、特写放大情绪营造悬念；视角改变力量关系——仰视显高大权威、俯视显渺小脆弱、平视易代入
5. 角色一致性（最大挑战）：为每个分镜重复同一份完整角色关键特征描述（固定外貌+服饰词组，如"红帽子，蓝色连衣裙"）；建议用户配合以图生图/局部重绘；接受细微差异，优先保证故事连贯
6. 动态推进三原则：前后画面动作有逻辑关联（举→挥→放）、场景转换有逻辑、情绪随表情/色调/光影演进

### 第四步：输出规范

A/B/C 单图模式按以下结构输出：

```
【模式】A/B/C + 一句话说明
【提示词】组装完成的完整提示词（一段连贯中文，逗号分隔各要素）
【反向提示词】模糊、低劣画质、多余的手指、文字、水印（按需增删）
【要素拆解】按模板逐项列出所选要素，方便用户局部调整
【优化建议】1~2条可迭代方向（更换风格/视角/光影的A/B测试建议）
```

D 反推模式输出：模式说明 + 反推提示词 + 要素拆解（主体/风格/构图/光影/色彩）+ 四步加工建议（筛选/优化/补充/删除的具体项）+ 原创性提醒。

E 分镜模式输出：故事内核（一句话）+ 角色卡（固定描述词组，保证一致性）+ 分镜列表（每张含画面描述、构图/景别、完整提示词）+ 一致性与迭代提示。

## 生成要点

- 具体胜于抽象："一辆红色的复古跑车，在雨夜的城市柏油马路上飞驰，溅起水花"而非"一辆车在路上"
- 描述不具体时多问 W/H：什么（What）、谁（Who）、何时（When）、何地（Where）、怎么样（How）；"一朵花"→"一朵盛开的、带着露珠的红玫瑰"
- 善用感官词汇间接增强氛围（丝绸般光滑、寂静的森林、清冷的海风）
- 情境代入：思考主体正在做什么、情绪如何、周围发生了什么（"疲惫的骑士卸下盔甲坐在篝火旁"）
- 艺术家风格谨慎指名：AI 对"凡·高风格"等的理解受训练数据限制，优先描述风格特征（"厚涂笔触，鲜艳色彩"）；风格可组合但需协调（"赛博朋克风格的浮世绘"）
- 质量词适度，过度堆砌会导致效果不佳
- 迭代方法论：从小处着手（先核心主体+基本风格）→ 逐步添加（每次增改少量关键词观察变化）→ A/B 测试（同主体换风格/描述词对比）→ 借鉴学习（参考优秀作品提示词，保持原创）
- 提示词难以写出理想效果时，建议用户使用以图生图+蒙版局部重绘（Inpainting）修正细节，对保持角色一致性极有效
- 需要精准关键词（构图/光影/色彩/风格/材质）时，读取 `references/keywords.md` 速查表选词
- 需要成品参考时，读取 `references/examples.md`
