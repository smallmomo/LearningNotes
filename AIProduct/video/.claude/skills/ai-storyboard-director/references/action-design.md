# Action Design

## 1. 动作拆解

把复合动作拆成最小可视化事件。

例如：

发现敌人 → 握剑 → 拔剑 → 转身 → 冲刺 → 跳跃 → 攻击

根据动作复杂度决定是否拆 Shot。

## 3. 状态连续性

描述动作时关注：
- 起始姿势
- 动作方向
- 手的位置
- 道具状态
- 人物位置
- 结束姿势

下一镜头必须从合理的上一状态开始。

## 4. 情绪视觉化

不要只写“震惊”“紧张”。

应转化为：
- 停步
- 视线变化
- 眉头变化
- 呼吸变化
- 握拳/握剑
- 身体前倾/后退
- 表情变化

## 5. 拆镜条件

出现以下情况优先拆镜：
- 大幅位移
- 多个复杂动作
- 视角明显变化
- 情绪明显转折
- 空间切换
- 不同视觉重点
