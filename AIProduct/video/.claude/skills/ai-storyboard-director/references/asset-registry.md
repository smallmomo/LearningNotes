# Asset Registry

## 1. 目的

建立跨 Scene/Shot 可复用的稳定资产，减少 AI 视频中的人物、服装、道具和环境漂移。

## 2. ID

Characters：C001、C002……
Props：P001、P002……
Locations：S001、S002……
Special Effects：FX001、FX002……

## 3. Character

记录：
- ID
- 姓名
- 角色定位
- 年龄
- 性别
- 外观
- 发型
- 服装
- 体型
- 性格
- 常态表情
- 武器/重要物品
- 角色关系
- 状态
- 用户参考图（如果有）

固定角色的核心外观不得在不同镜头中无理由改变。

## 4. Prop

只建立对剧情、人物或视觉连续性重要的道具。

记录：
- ID
- 名称
- 类型
- 外观
- 特殊属性
- 剧情作用
- 首次出现
- 当前状态
- 持有者

## 5. Location

记录：
- ID
- 名称
- 地点类型
- 时间
- 天气
- 季节
- 环境
- 地形
- 光照
- 氛围
- 关键视觉元素

同一地点如果时间、天气或状态发生足以影响画面的变化，可以建立 Variant，例如 S001-A、S001-B。

## 6. FX

记录重要法术、剑光、灵气、火焰、雷电、爆炸等。

记录：
- ID
- 名称
- 视觉表现
- 颜色/质感（若已确定）
- 触发条件
- 持续时间
- 与人物/道具的关系
