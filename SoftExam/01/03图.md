
# 1. 图 - 邻接表

## 一、先记2个基础定义
1. **表头结点**：代表图的**顶点**
2. **边表结点**：代表**一条边**，挂在顶点后面的链表

---
## 二、无向图 实例
### 1. 无向图顶点 & 边
顶点：1、2、3  
无向边：
(1,2)、(1,3)、(2,3)

### 2. 邻接表结构（文字可视化）
```
顶点1(表头) → 2 → 3 ∧
顶点2(表头) → 1 → 3 ∧
顶点3(表头) → 1 → 2 ∧
```
### 3. 考点计算
- 边数量：3 条
- 边表结点总数：   
  3 * 2 = 6 个（偶数）
  ✅ 无向图：一条边 = 2个边结点

---
## 三、有向图 实例
### 1. 有向图顶点 & 边
顶点： 1、2、3  
有向边： (1 to 2,  1 to 3, 2 to 3)

### 2. 邻接表结构
```
顶点1(表头) → 2 → 3 ∧
顶点2(表头) → 3 ∧
顶点3(表头) ∧ （无出边，空链表）
```
### 3. 考点计算
- 有向边数量：3 条
- 边表结点总数：3 个（**可以是奇数**）  
  ✅ 有向图：一条边 = 1个边结点

---
## 四、必背结论
1. 无向图邻接表：**边表结点总数必为偶数**
2. 有向图邻接表：边表结点总数**可奇、可偶**
3. 题目出现：「无向图邻接表边结点为奇数」→ 直接判错

---
## 五、结构对应关系
- 每行开头 = 顶点（表头）
- 箭头后面每一个数字 = 1个**边表结点**
- 链表长度 = 该顶点的**度**
    - 无向图：链表长 = 顶点度
    - 有向图：链表长 = 出度

结合考点，极简说：
1. **无向图**
   一条无向边 $(u,v)$，会**产生2个重复的边表结点**：
   $u$ 存 $v$、$v$ 存 $u$，双向重复记录。

2. **有向图**
   一条有向边只存1次，**没有重复边表结点**。

---
应试一句话：
无向边双向存、边表结点重复；有向边单向存、无重复。

# 2. 图 - 邻接矩阵
## 邻接矩阵（Adjacency Matrix）

邻接矩阵是一种表示图（Graph）的存储方式。

核心思想：

> 用一个二维数组来表示“顶点之间是否有边”。

如果有 `n` 个顶点，就创建一个 `n × n` 的矩阵。

---

## 一、适用于什么场景

邻接矩阵适合：

* 顶点不多
* 边很多（稠密图）
* 经常判断两个点是否相连

例如：

* 社交关系图
* 城市路线图
* 网络拓扑图

---

## 二、无向图示例

假设有一个无向图：

```text
A —— B
|    /
|   /
C
```

顶点：

```text
A B C
```

边：

```text
A-B
A-C
B-C
```

---

## 三、邻接矩阵表示

先给顶点编号：

```text
A -> 0
B -> 1
C -> 2
```

创建矩阵：

```text
      A B C
    ----------
A |   0 1 1
B |   1 0 1
C |   1 1 0
```

含义：

* `matrix[0][1] = 1`
  表示 A 和 B 有边

* `matrix[1][2] = 1`
  表示 B 和 C 有边

* `0`
  表示没有边

---

## 四、为什么无向图是对称的

因为：

```text
A -> B
```

和：

```text
B -> A
```

本质是同一条边。

所以：

```text
matrix[i][j] == matrix[j][i]
```

矩阵关于对角线对称。

---

## 五、有向图示例

有向图：

```text
A → B
A → C
C → B
```

邻接矩阵：

```text
      A B C
    ----------
A |   0 1 1
B |   0 0 0
C |   0 1 0
```

这里：

```text
matrix[i][j]
```

表示：

> i 是否指向 j

例如：

```text
matrix[A][B] = 1
```

表示：

```text
A → B
```

但：

```text
matrix[B][A] = 0
```

说明：

```text
B 没有指向 A
```

---

## 六、带权图（最重要）

如果边有“权值”，矩阵中存储的就不是 1。

例如：

```text
A --5-- B
|       |
2       1
|       |
C --8-- D
```

矩阵：

```text
      A  B  C  D
A |   0  5  2  ∞
B |   5  0  ∞  1
C |   2  ∞  0  8
D |   ∞  1  8  0
```

这里：

* 数字表示权值
* `∞` 表示不可达

例如：

```text
A -> B 的距离是 5
```

---

## 七、Java 实现示例

### 无向图

```java
public class GraphMatrix {

    // 顶点数组
    private String[] vertex = {"A", "B", "C"};

    // 邻接矩阵
    private int[][] matrix = new int[3][3];

    public GraphMatrix() {

        // A-B
        matrix[0][1] = 1;
        matrix[1][0] = 1;

        // A-C
        matrix[0][2] = 1;
        matrix[2][0] = 1;

        // B-C
        matrix[1][2] = 1;
        matrix[2][1] = 1;
    }

    public void print() {
        for (int[] row : matrix) {
            for (int value : row) {
                System.out.print(value + " ");
            }
            System.out.println();
        }
    }

    public static void main(String[] args) {
        new GraphMatrix().print();
    }
}
```

输出：

```text
0 1 1
1 0 1
1 1 0
```

---

## 八、邻接矩阵的时间复杂度

### 判断两点是否相连

```java
matrix[i][j]
```

直接访问即可。

时间复杂度：

```text
O(1)
```

非常快。

---

### 遍历某个顶点的所有邻居

需要扫描整行：

```text
O(n)
```

例如：

```text
A 的邻居是谁？
```

要看：

```text
matrix[A][0...n]
```

---

## 九、空间复杂度

邻接矩阵需要：

```text
n × n
```

空间。

所以空间复杂度：

```text
O(n²)
```

如果图很大但边很少：

```text
10000 个点
只有 20 条边
```

那么矩阵会非常浪费空间。

---

## 十、邻接矩阵 vs 邻接表

| 对比     | 邻接矩阵 | 邻接表   |
| ------ | ---- | ----- |
| 存储结构   | 二维数组 | 链表/集合 |
| 判断是否相连 | O(1) | O(k)  |
| 节省空间   | 差    | 好     |
| 适合     | 稠密图  | 稀疏图   |
| 遍历邻居   | O(n) | O(k)  |

其中：

```text
k = 当前节点的边数
```

---

## 十一、一个经典理解方式

邻接矩阵本质就是：

> “城市之间是否有路”的表格。

例如：

|    | 北京 | 上海 | 深圳 |
| -- | -- | -- | -- |
| 北京 | 0  | 1  | 1  |
| 上海 | 1  | 0  | 0  |
| 深圳 | 1  | 0  | 0  |

表示：

* 北京能到上海
* 北京能到深圳
* 上海不能直接到深圳

本质就是：

```text
点 与 点 的关系表
```
