# 1. UML 四大关系
UML 中有 4 种关系：
依赖、关联、泛化、实现
```
聚合、组合其实属于： 关联关系的特殊形式
```

所以严格来说：

```text id="j7n5wu"
聚合、组合 ⊂ 关联
```

---

## UML 常见四大关系

| 关系 | 英文             | 本质   |
| -- | -------------- | ---- |
| 依赖 | Dependency     | 临时使用 |
| 关联 | Association    | 长期引用 |
| 泛化 | Generalization | 继承   |
| 实现 | Realization    | 接口实现 |

---

# 一、依赖（Dependency）

## 核心思想

```text id="x3w6qn"
一个类“使用”另一个类
```

通常：

* 方法参数
* 局部变量
* 方法调用

---

## UML 表示

```text id="n4m8tr"
虚线箭头
```

```text id="f7q2ls"
A - - - > B
```

---

## 示例

### Computer

```java id="u8v2mi"
public class Computer {

    public void start() {
        System.out.println("电脑启动");
    }
}
```

---

### Person

```java id="c3z6ta"
public class Person {

    public void use(Computer computer) {
        computer.start();
    }
}
```

---

## 为什么是依赖？

因为：

```text id="w5q1xe"
Person 只是临时使用 Computer
```

没有：

```text id="y9r4jm"
成员变量持有
```

---

## 特点

| 特点     | 说明   |
| ------ | ---- |
| 临时关系   | 方法级别 |
| 耦合弱    | 最弱   |
| 生命周期独立 | 互不影响 |

---

# 二、关联（Association）

## 核心思想

```text id="j6w3pz"
一个类长期持有另一个类
```

通常：

```text id="r4x8tm"
成员变量引用
```

---

## UML 表示

```text id="t8p2qv"
实线箭头
```

```text id="n9w5ok"
Student ------> School
```

---

## 示例

### School

```java id="g5n7pr"
public class School {

    private String name;
}
```

---

### Student

```java id="t2q6fj"
public class Student {

    private School school;
}
```

---

## 为什么是关联？

因为：

```text id="u2q9mw"
Student 长期持有 School
```

---

## 特点

| 特点     | 说明    |
| ------ | ----- |
| 长期关系   | 成员变量  |
| 生命周期独立 | 可单独存在 |
| 比依赖强   | 更稳定   |

---

# 三、泛化（Generalization）

## 核心思想

```text id="z7k2vf"
继承关系
```

即：

```text id="x8m1lo"
is-a
```

关系。

---

## UML 表示

```text id="k4t9ju"
实线 + 空心三角
```

```text id="m1x5wr"
Dog ─────▷ Animal
```

箭头指向：

```text id="b3v7yn"
父类
```

---

## 示例

### 父类

```java id="r9m2vx"
public class Animal {

    public void eat() {
        System.out.println("吃东西");
    }
}
```

---

### 子类

```java id="p4w6zt"
public class Dog extends Animal {

}
```

---

## 为什么叫泛化？

因为：

```text id="u6q4ns"
Dog 是 Animal 的一种
```

父类：

```text id="v5n8dx"
更泛
```

子类：

```text id="h2r1mq"
更具体
```

所以叫：

```text id="s9x3tb"
泛化
```

---

## 特点

| 特点   | 说明      |
| ---- | ------- |
| 继承关系 | extends |
| is-a | 是一种     |
| 代码复用 | 继承父类能力  |

---

# 四、实现（Realization）

## 核心思想

```text id="o5n7qa"
类实现接口
```

---

## UML 表示

```text id="m8v2rw"
虚线 + 空心三角
```

```text id="d4x9pk"
UserServiceImpl - - -▷ UserService
```

---

## 示例

### 接口

```java id="u3n6ka"
public interface UserService {

    void save();
}
```

---

### 实现类

```java id="q1w8fd"
public class UserServiceImpl
        implements UserService {

    @Override
    public void save() {
        System.out.println("保存用户");
    }
}
```

---

## 为什么叫实现？

因为：

```text id="z2p5tc"
接口只定义规范
```

实现类：

```text id="x4k7mw"
真正实现功能
```

---

## 特点

| 特点     | 说明         |
| ------ | ---------- |
| 接口实现   | implements |
| 面向抽象编程 | 高扩展        |
| 解耦     | 非常重要       |

# UML 关联、聚集、组合 3个区别
先记一句话总纲：
**关联=普通有关系**
**聚集=整体–部分，可分开、可各自独立**
**组合=整体–部分，生死绑定、同生共死**

---

## 1. 关联（Association）
**含义**：两个类**普通有关系**，谁也不是谁的一部分，平等关系。
- 关系最弱
- 双向可关联，互不拥有、互不依赖
- UML符号：**实线**

例子：
- 学生 —— 老师
- 顾客 —— 订单
  学生没了老师还在，老师没了学生还在，**只是有关系而已**。

---

## 2. 聚集 / 聚合（Aggregation）
**含义**：**整体—部分关系**，但**部分可以脱离整体独立存在**。
- 空心菱形 ◇ 在整体那一端
- 弱拥有：**整体没了，部分还能活着**
- 是「has-a」松散关系

经典例子：**汽车 和 轮胎**
- 汽车报废了，轮胎还可以拆下来装别的车上
- 部分可脱离整体，各自独立

再举例：班级 ◇ 学生
班级解散，学生还在，还能去别的班级。

---

## 3. 组合（Composition）
**含义**：**强整体–部分，生死绑定**
- 实心菱形 ◆ 在整体那一端
- 整体没了 → 部分也跟着消失
- 部分**不能脱离整体单独存在**
- 生命周期完全绑定

经典例子：**人和心脏**
- 人没了，心脏也就没用了、跟着消亡
- 心脏不能拆出去给别人用（逻辑上生命周期绑定）

再举例：
房子 ◆ 房间
房子拆了，房间直接没了，不能单独存在。

---

## 极简对比口诀（考试直接背）
1. **关联**：实线，普通认识、平等关系
2. **聚集（聚合）**：空心菱形，整体–部分，**可分家、各自活**
3. **组合**：实心菱形，整体–部分，**同生共死、不能分家**

---

## 一秒区分万能判断法
给你两个类，判断顺序：
1. 是不是谁包含谁？不是 → **关联**
2. 包含关系，部分能不能离开整体独立存在？
    - 能 → **聚集（空心）**
    - 不能、整体挂了部分也挂 → **组合（实心）**
