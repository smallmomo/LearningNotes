

# 1.插入排序
## 一、算法核心思想
**直接插入排序**的核心逻辑：
1.  将数组分为「已排序区间（左边）」和「未排序区间（右边）」
2.  每次从未排序区间取第一个元素，向前插入到已排序区间的合适位置
3.  重复上述过程，直到整个数组有序

---

## 二、完整代码
```c
void Insertsort(int data[], int n )
/*将数组 data[0]～data[n-1]中的 n 个整数按非递减有序的方式进行排列*/
{
    int i, j;
    int tmp;
    for(i = 1; i < n; i++) {
        if (data[i] < data[i-1]) {
            tmp = data[i];  
            data[i] = data[i-1];
            for(j = i-1; j >= 0 && data[j] > tmp; j--)  
                data[j+1] = data[j];
            data[j+1] = tmp;
        }/*if*/
    }/*for*/
}/*Insertsort*/
```

---

## 三、逐行解析
### 1. 函数与变量定义
```c
void Insertsort(int data[], int n )
int i, j;
int tmp;
```
- `data[]`：待排序数组
- `n`：数组元素个数
- `i`：外层循环变量，指向「未排序区间」的第一个元素
- `j`：内层循环变量，向前扫描「已排序区间」
- `tmp`：暂存当前待插入元素，防止移动时被覆盖

---

### 2. 外层循环：逐个处理未排序元素
```c
for(i = 1; i < n; i++) {
```
- `i` 从 `1` 开始（`data[0]` 初始为已排序区间）
- 每轮循环处理 `data[i]`，将其插入到前面的已排序区间

---

### 3. 优化判断：无需插入的情况
```c
if (data[i] < data[i-1]) {
```
- 若 `data[i] >= data[i-1]`，说明它已经在正确位置，直接跳过内层循环
- 仅当 `data[i] < data[i-1]` 时，才需要向前插入

---

### 4. 暂存元素，准备移动
```c
tmp = data[i];  
data[i] = data[i-1];
```
- `tmp = data[i]`：保存待插入元素的值
- `data[i] = data[i-1]`：先把前一个元素后移一位，腾出空间（非必须，不影响核心逻辑）

---

### 5. 内层循环：向前扫描并移动元素
```c
for(j = i-1; j >= 0 && data[j] > tmp; j--)  
    data[j+1] = data[j];
```
- 从 `i-1` 开始向前扫描：
    - 若 `data[j] > tmp`，则将 `data[j]` 后移一位（`data[j+1] = data[j]`）
    - 循环结束时，`j` 停在第一个 `data[j] <= tmp` 的位置
- 此时 `j+1` 就是 `tmp` 应该插入的位置

---

### 6. 插入元素，完成本轮排序
```c
data[j+1] = tmp;
```
- 将暂存的 `tmp` 放到 `j+1` 位置，完成一次插入

---

## 四、完整示例走一遍
以数组 `[5, 2, 4, 6, 1, 3]` 为例：

| 轮次(i) | 待插入元素 | 操作过程 | 数组结果 |
|---------|------------|----------|----------|
| 1       | 2          | 2比5小，插入到最前 | `[2,5,4,6,1,3]` |
| 2       | 4          | 4在2和5之间，插入到中间 | `[2,4,5,6,1,3]` |
| 3       | 6          | 6比5大，无需移动 | `[2,4,5,6,1,3]` |
| 4       | 1          | 1比所有元素小，插入到最前 | `[1,2,4,5,6,3]` |
| 5       | 3          | 3在2和4之间，插入到中间 | `[1,2,3,4,5,6]` |

---

## 五、关键特性（软考必背）
| 特性 | 说明 |
|------|------|
| 最好时间复杂度 | \(O(n)\)（数组已升序时，内层循环不执行） |
| 最坏/平均时间复杂度 | \(O(n^2)\)（数组逆序时，每次都要移到最前面） |
| 空间复杂度 | \(O(1)\)（原地排序，仅用一个临时变量） |
| 稳定性 | 稳定排序（相等元素的相对位置不变） |
| 适用场景 | 小规模数据、接近有序的数据 |

## 六、极简版代码（去掉优化判断）
去掉 `if` 判断，逻辑更通用：
```c
void Insertsort(int data[], int n ) {
    int i, j, tmp;
    for(i = 1; i < n; i++) {
        tmp = data[i];
        for(j = i-1; j >= 0 && data[j] > tmp; j--) {
            data[j+1] = data[j];
        }
        data[j+1] = tmp;
    }
}
```

# 软考必考：快速排序 超通俗详解（原理+步骤+复杂度+稳定性）
## 一、核心思想
**分治 + 挖坑填数 + 基准值（pivot）**
1. 在数组里随便选一个数当**基准值**
2. 把比基准小的放左边，比基准大的放右边 → **一趟划分**
3. 左右两边再各自递归做同样操作
4. 直到每个区间只剩1个元素，整体有序

一句话：**选个基准，小左大右，左右递归**

---
## 二、最简单流程演示
数组：`[5,3,8,4,2,7]`
选第一个 5 做基准：
- 小于5：3、4、2
- 大于5：8、7
  一趟后：`[3,4,2, 5, 8,7]`
  再递归排左边 `[3,4,2]`、右边 `[8,7]`

---
## 三、标准规则（软考答题用）
1. 属于 **交换排序**
2. 核心：**划分 + 递归**
3. 每趟确定**基准元素的最终位置**

---
## 四、时间/空间复杂度、稳定性（必背）
### 时间复杂度
- 平均：**$O(n\log n)$**
- 最好：**$O(n\log n)$** 基准每次中分
- 最坏：**$O(n^2)$** 数组已有序/逆序，选首元素当基准

### 空间复杂度
- 递归栈：平均 **$O(\log n)$**，最坏 **$O(n)$**

### 稳定性
**不稳定排序**
举例：相同数值相对位置可能被打乱

---
## 五、优缺点
✅ 优点
- 平均速度最快，实际工程最常用
- 适合大数据量

❌ 缺点
- 最坏情况性能差
- 不稳定
- 递归消耗栈空间
