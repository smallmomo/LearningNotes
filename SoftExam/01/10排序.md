

# 1.插入排序
## 一、算法核心思想
**直接插入排序**的核心逻辑：
1.  将数组分为「已排序区间（左边）」和「未排序区间（右边）」
2.  每次从未排序区间取第一个元素，向前插入到已排序区间的合适位置
3.  重复上述过程，直到整个数组有序

---

## 二、完整代码
```c
void Insertsort(int data[], int n )
/*将数组 data[0]～data[n-1]中的 n 个整数按非递减有序的方式进行排列*/
{
    int i, j;
    int tmp;
    for(i = 1; i < n; i++) {
        if (data[i] < data[i-1]) {
            tmp = data[i];  
            data[i] = data[i-1];
            for(j = i-1; j >= 0 && data[j] > tmp; j--)  
                data[j+1] = data[j];
            data[j+1] = tmp;
        }/*if*/
    }/*for*/
}/*Insertsort*/
```

---

## 三、逐行解析
### 1. 函数与变量定义
```c
void Insertsort(int data[], int n )
int i, j;
int tmp;
```
- `data[]`：待排序数组
- `n`：数组元素个数
- `i`：外层循环变量，指向「未排序区间」的第一个元素
- `j`：内层循环变量，向前扫描「已排序区间」
- `tmp`：暂存当前待插入元素，防止移动时被覆盖

---

### 2. 外层循环：逐个处理未排序元素
```c
for(i = 1; i < n; i++) {
```
- `i` 从 `1` 开始（`data[0]` 初始为已排序区间）
- 每轮循环处理 `data[i]`，将其插入到前面的已排序区间

---

### 3. 优化判断：无需插入的情况
```c
if (data[i] < data[i-1]) {
```
- 若 `data[i] >= data[i-1]`，说明它已经在正确位置，直接跳过内层循环
- 仅当 `data[i] < data[i-1]` 时，才需要向前插入

---

### 4. 暂存元素，准备移动
```c
tmp = data[i];  
data[i] = data[i-1];
```
- `tmp = data[i]`：保存待插入元素的值
- `data[i] = data[i-1]`：先把前一个元素后移一位，腾出空间（非必须，不影响核心逻辑）

---

### 5. 内层循环：向前扫描并移动元素
```c
for(j = i-1; j >= 0 && data[j] > tmp; j--)  
    data[j+1] = data[j];
```
- 从 `i-1` 开始向前扫描：
    - 若 `data[j] > tmp`，则将 `data[j]` 后移一位（`data[j+1] = data[j]`）
    - 循环结束时，`j` 停在第一个 `data[j] <= tmp` 的位置
- 此时 `j+1` 就是 `tmp` 应该插入的位置

---

### 6. 插入元素，完成本轮排序
```c
data[j+1] = tmp;
```
- 将暂存的 `tmp` 放到 `j+1` 位置，完成一次插入

---

## 四、完整示例走一遍
以数组 `[5, 2, 4, 6, 1, 3]` 为例：

| 轮次(i) | 待插入元素 | 操作过程 | 数组结果 |
|---------|------------|----------|----------|
| 1       | 2          | 2比5小，插入到最前 | `[2,5,4,6,1,3]` |
| 2       | 4          | 4在2和5之间，插入到中间 | `[2,4,5,6,1,3]` |
| 3       | 6          | 6比5大，无需移动 | `[2,4,5,6,1,3]` |
| 4       | 1          | 1比所有元素小，插入到最前 | `[1,2,4,5,6,3]` |
| 5       | 3          | 3在2和4之间，插入到中间 | `[1,2,3,4,5,6]` |

---

## 五、关键特性（软考必背）
| 特性 | 说明 |
|------|------|
| 最好时间复杂度 | \(O(n)\)（数组已升序时，内层循环不执行） |
| 最坏/平均时间复杂度 | \(O(n^2)\)（数组逆序时，每次都要移到最前面） |
| 空间复杂度 | \(O(1)\)（原地排序，仅用一个临时变量） |
| 稳定性 | 稳定排序（相等元素的相对位置不变） |
| 适用场景 | 小规模数据、接近有序的数据 |

---

## 六、极简版代码（去掉优化判断）
去掉 `if` 判断，逻辑更通用：
```c
void Insertsort(int data[], int n ) {
    int i, j, tmp;
    for(i = 1; i < n; i++) {
        tmp = data[i];
        for(j = i-1; j >= 0 && data[j] > tmp; j--) {
            data[j+1] = data[j];
        }
        data[j+1] = tmp;
    }
}
```

# 2. 快速排序 超通俗详解
## 一、核心思想
**分治 + 挖坑填数 + 基准值（pivot）**
1. 在数组里随便选一个数当**基准值**
2. 把比基准小的放左边，比基准大的放右边 → **一趟划分**
3. 左右两边再各自递归做同样操作
4. 直到每个区间只剩1个元素，整体有序

一句话：**选个基准，小左大右，左右递归**

---
## 二、最简单流程演示
数组：`[5,3,8,4,2,7]`
选第一个 5 做基准：
- 小于5：3、4、2
- 大于5：8、7
  一趟后：`[3,4,2, 5, 8,7]`
  再递归排左边 `[3,4,2]`、右边 `[8,7]`

---
## 三、标准规则（软考答题用）
1. 属于 **交换排序**
2. 核心：**划分 + 递归**
3. 每趟确定**基准元素的最终位置**

---
## 四、时间/空间复杂度、稳定性（必背）
### 时间复杂度
- 平均：**$O(n\log n)$**
- 最好：**$O(n\log n)$** 基准每次中分
- 最坏：**$O(n^2)$** 数组已有序/逆序，选首元素当基准

### 空间复杂度
- 递归栈：平均 **$O(\log n)$**，最坏 **$O(n)$**

### 稳定性
**不稳定排序**
举例：相同数值相对位置可能被打乱

---
## 五、优缺点
✅ 优点
- 平均速度最快，实际工程最常用
- 适合大数据量

❌ 缺点
- 最坏情况性能差
- 不稳定
- 递归消耗栈空间

---
## 六、软考秒杀口诀
**快排分治选基准，小左大右递归整；
平均对数平方坏，排序不稳记得清。**

# 3.归并排序

## 一、核心思想
**分治思想**：
1. **分**：把数组**对半拆成两半**，一直拆到只剩1个元素（天然有序）
2. **治**：把两个**有序小数组**，合并成一个**大的有序数组**

稳定排序、时间复杂度始终 **O(nlogn)**，空间复杂度 **O(n)**。

## 二、两大特点
- 稳定排序（相等元素相对位置不变）
- 最好/最坏/平均都是**O(nlogn)**
- 需要额外辅助空间

## 三、完整原理步骤
1. 把待排序数组不断**二分拆分**，直到每个子数组只有1个元素
2. 两两**合并**两个有序子数组
3. 重复合并，最后合成整个有序数组

---

# 四、实例手把手演算
待排序数组：  
{38,27,43,3,9,82,10}

### 第一步：不断拆分（分）
第一层拆分：  
{38,27,43}{3,9,82,10}

继续拆：  
{38},{27,43}{3,9},{82,10}  

再拆到单个元素：    
{38},{27},{43},{3},{9},{82},{10}
  
单个元素默认**已有序**。

---

### 第二步：两两合并（治）
1. 合并 {38}、{27}  
   {27,38}
2. 合并 {43} 还是 {43}
3. 合并 {3}、{9}  
   {3,9}
4. 合并 {82}、{10}    
   {10,82}

现在得到：  
{27,38},{43},{3,9},{10,82}

继续往上合并：  
合并 {27,38} 和 {43} → {27,38,43}  
合并 {3,9} 和 {10,82} → {3,9,10,82}

最后合并两大块：  
{27,38,43}+{3,9,10,82}

最终有序结果：  
{3,9,10,27,38,43,82}

---

# 五、合并规则（重点）
有两个有序数组 A、B：
1. 各拿开头第一个数比较
2. 小的先放进新数组
3. 谁小谁往后移
4. 有一个数组取完，剩下的直接全部抄到后面

---

# 六、软考必背总结
1. 原理：**分而治之，先拆分、后合并**
2. 时间复杂度：**O(nlogn)** 稳定不变
3. 空间复杂度：**O(n)** 需额外空间
4. 稳定性：**稳定排序**
5. 适合：大数据量、外排序

---

# 七、极简口诀
**对半拆分到单个，两两合并成有序；
nlogn 稳时间，额外空间不能省。**

参考代码MergeSort
```java

public class MergeSort {

    public static void mergeSort(int[] arr, int left, int right) {

        // 递归结束
        if (left >= right) {
            return;
        }

        // 中间位置
        int mid = left + (right - left) / 2;

        // 排序左边
        mergeSort(arr, left, mid);

        // 排序右边
        mergeSort(arr, mid + 1, right);

        // 合并
        merge(arr, left, mid, right);
    }

    public static void merge(int[] arr,
                             int left,
                             int mid,
                             int right) {

        // 临时数组
        int[] temp = new int[right - left + 1];

        int i = left;
        int j = mid + 1;
        int k = 0;

        // 两边同时比较
        while (i <= mid && j <= right) {

            if (arr[i] <= arr[j]) {
                temp[k++] = arr[i++];
            } else {
                temp[k++] = arr[j++];
            }
        }

        // 左边剩余
        while (i <= mid) {
            temp[k++] = arr[i++];
        }

        // 右边剩余
        while (j <= right) {
            temp[k++] = arr[j++];
        }

        // 拷贝回原数组
        for (int p = 0; p < temp.length; p++) {
            arr[left + p] = temp[p];
        }
    }

    public static void main(String[] args) {

        int[] arr = {8,4,5,7,1,3,6,2};

        mergeSort(arr, 0, arr.length - 1);

        for (int num : arr) {
            System.out.print(num + " ");
        }
    }
}
```
