# 1. 前缀编码

哈夫曼编码（Huffman Coding）其实就是**一种最经典的前缀编码（Prefix Code）实现方式**。你可以把它理解成：

> 👉 **在保证“无歧义解码”的前提下，让整体编码长度最短的一种压缩算法**

我分层帮你讲清楚（从直觉 → 原理 → 构造过程 → 代码思维）。

---

## 一、什么是“前缀编码”？

先搞懂这个，不然哈夫曼你会觉得很抽象。

### ✅ 定义

> 👉 **任意一个编码，都不是另一个编码的前缀**

---

### 🔍 举个例子

#### ❌ 非前缀编码（有歧义）

```text
A → 0
B → 01
```

👉 问题：

```text
01 到底是：
A + 1 ❓
还是 B ❓
```

💥 无法唯一解码

---

#### ✅ 前缀编码（无歧义）

```text
A → 0
B → 10
C → 11
```

👉 任意编码都不会“卡住”

```text
0110 → A C A
```

---

## 二、哈夫曼编码在干嘛？

一句话：

> 👉 **给“出现频率高的字符”更短的编码**

---

### 🔥 为什么这么做？

比如：

```text
字符串：AAAAABCD
```

出现次数：

| 字符 | 次数 |
| -- | -- |
| A  | 5  |
| B  | 1  |
| C  | 1  |
| D  | 1  |

---

#### ❌ 普通编码（固定长度）

```text
A=00, B=01, C=10, D=11
```

总长度：

```text
8 * 2 = 16 bits
```

---

#### ✅ 哈夫曼编码（变长）

```text
A=0
B=100
C=101
D=11
```

总长度：

```text
5*1 + 1*3 + 1*3 + 1*2 = 13 bits
```

更短

---

## 三、哈夫曼编码核心思想

> 👉 **构建一棵“最优二叉树”（哈夫曼树）**

规则：

* 左子树 = 0
* 右子树 = 1
* 叶子节点 = 字符

---

## 四、构建过程（重点）

### 🎯 步骤

#### 1️⃣ 初始化（按频率）

```text
A:5  B:1  C:1  D:1
```

---

#### 2️⃣ 每次选最小的两个合并

##### 第一次：

```text
B(1) + C(1) → 节点(2)
```

##### 第二次：


```text
节点(2) + D(1) → 节点(3)
```

##### 第三次：

```text
节点(3) + A(5) → 根(8)
```

## 五、如何生成编码？

从根节点出发：

* 向左走 → 加 `0`
* 向右走 → 加 `1`

---

### 👉 最终编码可能是：

| 字符 | 编码  |
| -- | --- |
| A  | 1   |
| B  | 000 |
| C  | 001 |
| D  | 01  |

（结构不同可能编码不同，但长度最优）

---

## 六、为什么它一定是“前缀编码”？

因为：

> 👉 **所有字符都在叶子节点**

这意味着：

* 没有一个编码会“停在中间节点”
* 所以不会成为别人的前缀

---

### 例子
**完全手推一遍哈夫曼树的构建过程

```text
A:5   B:1   C:1   D:1
```

---

## 一、整体规则（先记住）

每一步只做一件事：

> 👉 **从当前集合中选“权值最小的两个节点”，合并成一个新节点**

新节点规则：

```text
新权值 = 两个节点权值之和
```

---

## 二、第0步：初始化

把所有字符当作“独立节点”：

```text
A(5)   B(1)   C(1)   D(1)
```

---

## 三、第1步：选最小两个合并

最小的是：

```text
B(1) 和 C(1)
```

👉 合并：

```text
BC(2)
```

---

### 🌳 当前结构变成：

```text
      (2)
     /   \
   B(1)  C(1)

A(5)   D(1)   BC(2)
```

---

## 四、第2步：继续选最小两个

现在集合：

```text
A(5)   D(1)   BC(2)
```

最小的是：

```text
D(1) 和 BC(2)
```

👉 合并：

```text
DBC(3)
```

---

## 🌳 当前结构：

```text
        (3)
       /   \
    D(1)   (2)
           / \
         B(1) C(1)

A(5)   DBC(3)
```

---

## 五、第3步：最后一次合并

现在：

```text
A(5)   DBC(3)
```

👉 合并：

```text
root(8)
```

---

## 六、最终哈夫曼树

```text
            (8)
           /   \
        (3)     A(5)
       /   \
    D(1)   (2)
           / \
        B(1) C(1)
```

---

## 七、检查是否正确（很重要）

### ✅ 条件1：所有原始字符都在“叶子节点”

```text
A、B、C、D 都在最底层 ✔
```

---

### ✅ 条件2：每一步都是“最小两个合并”

过程回顾：

```text
1. B(1) + C(1) ✔
2. D(1) + 2 ✔
3. 3 + A(5) ✔
```

---

## 八、一个关键理解（很多人忽略）

👉 这棵树**不是唯一的**

比如：

第一步你也可以：

```text
B + D
```

而不是：

```text
B + C
```

👉 最终树结构会变，但：

> ✅ **总路径长度一定最优**

---

## 九、你现在应该掌握的核心

这道题你只要会三件事：

---

### 1️⃣ 找最小两个

```text
每一步都找最小
```

---

### 2️⃣ 合并成新节点

```text
新节点 = 左 + 右
```

---

### 3️⃣ 重复直到只剩一个节点

```text
最后就是根节点
```

---

## 十、一句话总结（非常重要）

> 👉 **哈夫曼树的构建过程，本质就是不断“贪心地合并当前最小的两个节点”，直到形成一棵完整二叉树**
