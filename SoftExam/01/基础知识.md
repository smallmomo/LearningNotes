
# 1. 散列表
## 一、通俗大白话：什么是 Hash / 散列 / 哈希表
## 1. 先记3个词
- **Hash（哈希/散列）**：把**任意长度内容**，通过算法，算出**固定长度的一串数字/值**
- **Hash函数**：计算公式
- **哈希表(散列表 HashTable)**：用 Hash 值当「下标」存数据的数组容器，**查询、插入、删除几乎 O(1) 极速**

---

## 二、举个最简单例子
我要存：姓名 → 手机号
正常数组：按顺序放，找名字要**逐个遍历**，很慢。

Hash 做法：
1. 对 key（姓名）执行 hash 算法，算出一个**数字下标**
2. 直接把数据存在数组「这个下标位置」
3. 查找时：再算一遍 key 的 hash → 直接定位下标取值

> 核心：**key 直接定位存储位置，不用遍历**

---

## 三、公式理解
```
存储下标 = hash(key) % 数组长度
```
示例：
key = "张三"
1. hash("张三") = 223288743138037248918854442825774964873
2. 对数组长度取余 → 得到合法数组下标
3. 存、查、删 一步到位

---

## 四、哈希冲突（必考，软设高频）
**问题**：不同的 key，算出了**同一个下标**
例：keyA 和 keyB，hash后下标一样 → 抢同一个位置

## 常见2种解决方式（软设必背）
1. **链地址法（拉链法）**
   数组每个位置不存单个元素，存**链表/红黑树**
   Java `HashMap` 就是：数组 + 链表 + 红黑树

2. **开放定址法**
   冲突了就往后找空位：
    - 线性探测
    - 二次探测
    - 随机探测

---

## 五、哈希表  vs  数组 / 链表
| 结构 | 查找 | 插入 | 删除 | 特点 |
|------|------|------|------|------|
| 数组 | O(n) | 慢 | 慢 | 有序、遍历快 |
| 链表 | O(n) | 快 | 快 | 只能逐个找 |
| **哈希表** | **O(1)** | **O(1)** | **O(1)** | 键值映射、极速查询 |

---

## 六、开发&软设常考经典实现
1. **HashMap**（Java）
    - 底层：哈希表 + 拉链法
    - JDK1.8：数组+链表，长度≥8转红黑树
2. **HashSet**
    - 底层就是 HashMap，只存 key
3. 散列表考点：
    - 散列函数设计
    - 冲突解决
    - 装填因子（负载因子）：`元素数/数组长度`，越大冲突越多

---

## 七、一句话极简总结
1. **哈希**：任意数据 → 固定数字摘要
2. **哈希表**：用 key 哈希值当下标，直接存取
3. 优势：**随机访问极快 O(1)**
4. 缺点：存在**哈希冲突**，需要额外方案解决

# 2. 树的度
## 1. 节点的度（单个节点）
**定义**：某个节点**拥有的子节点个数**
- 叶子节点（终端节点）：没有孩子 → **度 = 0**
- 只有1个孩子 → 度=1
- 有3个孩子 → 度=3

举例：
A 下面挂了 B、C、D
👉 节点A 的度 = **3**

---

## 2. 树的度（整棵树）
**定义**：整棵树里，**所有节点的度 的最大值**

举例：
树里所有节点度数分别是：`0,1,2,3,0,2`
最大值是 3
👉 **这棵树的度 = 3**

---

## 3. 超级好记口诀
- **节点的度**：自己有几个娃
- **树的度**：全家娃最多的那个数量

---

## 4. 常考补充（软设选择题）
1. 二叉树：
   规定**每个节点最多2个子节点**
   → 所以**二叉树的度 ≤ 2**
2. 叶子节点：度一定是 0
3. 孤立根节点（没孩子）：根节点度=0，树的度=0

---

## 5.小例题巩固
一棵树：
- 节点①：2个孩子
- 节点②：0个孩子
- 节点③：4个孩子
- 节点④：1个孩子

各节点度：2、0、4、1
👉 树的度 = **4**

### 核心公式
树通用公式：
n_0 = n_2 + 2n_3 + 3n_4 + ... + (k-1)n_k + 1

- \(n_0\)：叶子节点（度为0）
- \(n_1\)：度为1节点
- \(n_2\)：度为2节点
- \(n_3\)：度为3节点
- \(n_4\)：度为4节点

# 3. 邻接表 

## 一、先记2个基础定义
1. **表头结点**：代表图的**顶点**
2. **边表结点**：代表**一条边**，挂在顶点后面的链表

---
## 二、无向图 实例
### 1. 无向图顶点 & 边
顶点：1、2、3  
无向边：
(1,2)、(1,3)、(2,3)

### 2. 邻接表结构（文字可视化）
```
顶点1(表头) → 2 → 3 ∧
顶点2(表头) → 1 → 3 ∧
顶点3(表头) → 1 → 2 ∧
```
### 3. 考点计算
- 边数量：3 条
- 边表结点总数：   
 3 * 2 = 6 个（偶数）
  ✅ 无向图：一条边 = 2个边结点

---
## 三、有向图 实例
### 1. 有向图顶点 & 边
顶点： 1、2、3  
有向边： (1 to 2,  1 to 3, 2 to 3)

### 2. 邻接表结构
```
顶点1(表头) → 2 → 3 ∧
顶点2(表头) → 3 ∧
顶点3(表头) ∧ （无出边，空链表）
```
### 3. 考点计算
- 有向边数量：3 条
- 边表结点总数：3 个（**可以是奇数**）  
  ✅ 有向图：一条边 = 1个边结点

---
## 四、必背结论
1. 无向图邻接表：**边表结点总数必为偶数**
2. 有向图邻接表：边表结点总数**可奇、可偶**
3. 题目出现：「无向图邻接表边结点为奇数」→ 直接判错

---
## 五、结构对应关系
- 每行开头 = 顶点（表头）
- 箭头后面每一个数字 = 1个**边表结点**
- 链表长度 = 该顶点的**度**
   - 无向图：链表长 = 顶点度
   - 有向图：链表长 = 出度

结合考点，极简说：
1. **无向图**
   一条无向边 $(u,v)$，会**产生2个重复的边表结点**：
   $u$ 存 $v$、$v$ 存 $u$，双向重复记录。

2. **有向图**
   一条有向边只存1次，**没有重复边表结点**。

---
应试一句话：
无向边双向存、边表结点重复；有向边单向存、无重复。
